# 💰 Daily Expense Tracker

A simple and user-friendly web application to track daily expenses.
Add your expenses, select a payment category, and view your expense history in one place.

## ✨ Features

- ➕ Add new expenses
- 💵 Enter expense name and amount
- 🏷️ Select payment category (UPI, Cash, or Card)
- 📅 Select the expense date
- 🚫 Prevent selecting future dates
- 📊 View the total expense
- 📋 View expense history in a table
- 📱 Responsive user interface

## 🛠️ Technologies Used

- HTML5 – To structure the application
- CSS3 – To style the user interface
- JavaScript – To handle expense entries and calculations

## 🚀 How to Run

1. Clone this repository or download the project files.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter an expense name, amount, category, and date.
5. Click **Add Expense** to add the expense to the history table.
6. View the total expense and your expense history.
